# Holiday Home Website

Sito web sviluppato per la promozione e la gestione di una casa vacanze. Il progetto permette ai visitatori di visualizzare informazioni sulla struttura, consultare una galleria fotografica, verificare la disponibilità e contattare il proprietario.

## Obiettivi

- Presentare la struttura in modo chiaro e accattivante.
- Facilitare le richieste di prenotazione.
- Offrire un'esperienza utente intuitiva e responsive.

## Funzionalità

- Homepage con presentazione della casa vacanze
- Galleria immagini
- Descrizione servizi e dotazioni
- Informazioni sulla posizione
- Design responsive per dispositivi mobili e desktop

## Tecnologie Utilizzate

- HTML5
- CSS3
- TypeScript
- React
